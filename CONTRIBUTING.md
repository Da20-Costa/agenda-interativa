# Como Contribuir

Obrigado por considerar contribuir para a Agenda Interativa!

## Processo de Desenvolvimento

1. Faça um Fork deste repositório.
2. Crie uma branch para a sua feature (`git checkout -b feature/minha-feature`).
3. Faça o commit das suas mudanças (`git commit -m 'feat: adiciona nova funcionalidade'`).
4. Faça o push para a branch (`git push origin feature/minha-feature`).
5. Abra um Pull Request.

## Padrões de Código

- Certifique-se de que todos os testes estão passando (`npm test`).
- Siga os padrões de linting do projeto.

## Reportando Problemas de Segurança

A proteção de dados e a segurança são prioridades. Caso encontre alguma vulnerabilidade ou falha de segurança na forma como o aplicativo lida com a persistência local, por favor, não abra uma _Issue_ pública. Entre em contato diretamente para que possamos aplicar as políticas de mitigação adequadas antes da divulgação.
